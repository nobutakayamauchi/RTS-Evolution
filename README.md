## The five surviving principles from WITNESS

WITNESS did not survive as a software platform. Its final necessity tests left five semantic rules:

1. Preserve the original requested outcome and completion conditions.
2. Preserve `UNKNOWN / CONFLICT`; missing proof must not become success.
3. Define what may become canonical project truth.
4. Require materially separated review for materially fallible completion judgments.
5. Preserve the fact and reason when a test, evaluator, observation, or implementation was defective.

These principles are the constitutional starting point for RTS Evolution.

## What RTS Evolution is

RTS Evolution is not a continuation of the old RTS architecture by default.

It asks whether the useful responsibilities of RTS can be reconstructed from:

- existing AI and external tools;
- Git / GitHub and ordinary repository primitives;
- provider-native runtime and deployment evidence;
- existing CI and testing systems;
- human authority where final judgment or external action matters;
- only the smallest custom glue that survives destructive evaluation.

The goal is not to preserve RTS as a monument.

The goal is to preserve and strengthen the responsibilities that still deserve to exist.

## Canonical boundary

This repository owns **RTS Evolution**.

It does **not** own:

- the historical old RTS record — preserved in [`nobutakayamauchi/RTS`](https://github.com/nobutakayamauchi/RTS);
- WITNESS as software — its standalone build was rejected; the experiment remains in [`nobutakayamauchi/WITNESS`](https://github.com/nobutakayamauchi/WITNESS);
- Ultimate Loop as a development method — it emerged while RTS Evolution was being built and will have its own canonical repository.

## Migration rule

**Copy the survivor, preserve the graveyard.**

The old RTS repository remains historical evidence. RTS Evolution receives only the current survivor surface and the references required to prove where it came from.

No historical failure, rejected design, or prior completion death is silently rewritten into success.
